# Audio Chat Troubleshooting Guide

## 1. **API Configuration Issues**

### Problem: Incorrect Gemini API Setup
Your `generateGeminiResponse` function uses an outdated API call format:

```javascript
// ❌ Incorrect - This format doesn't exist
const result = await genAI.models.generateContent({
  model: 'gemini-2.0-flash',
  contents: [...],
  config: { ... }
});
```

### Solution: Fix API Call Format
```javascript
// ✅ Correct format
const model = genAI.getGenerativeModel({ model: 'gemini-2.0-flash' });
const result = await model.generateContent({
  contents: [...],
  generationConfig: {
    maxOutputTokens: 300,
    temperature: 0.7,
    topP: 0.8,
    topK: 40,
  },
  safetySettings: [...]
});
```

## 2. **Audio Upload and Processing Issues**

### Problem: MIME Type Mismatch
Your multer configuration accepts any audio file, but you're hardcoding `audio/webm` in the Gemini call:

```javascript
// ❌ Hardcoded MIME type
inlineData: {
  mimeType: 'audio/webm',  // This might not match the actual file
  data: audioBuffer.toString('base64')
}
```

### Solution: Use Dynamic MIME Type
```javascript
// ✅ Use the actual file MIME type
export async function transcribeAudioWithGemini(audioBuffer: Buffer, mimeType: string) {
  // ... other code
  {
    inlineData: {
      mimeType: mimeType, // Use the actual MIME type from multer
      data: audioBuffer.toString('base64')
    }
  }
  // ... rest of function
}

// Update the route handler
router.post("/", upload.single('audio'), async (req, res) => {

    lesson, 
    audioFile.buffer,

```

## 4. **File Size and Format Validation**

### Problem: Limited Error Handling
Your current validation is basic and might miss edge cases.

### Solution: Enhanced Validation
```javascript
const upload = multer({
  storage: multer.memoryStorage(),
  limits: {
    fileSize: 10 * 1024 * 1024, // 10MB limit
  },
  fileFilter: (req, file, cb) => {
    // Check for supported audio formats
    const supportedMimeTypes = [
      'audio/wav',
      'audio/mp3', 
      'audio/mpeg',
      'audio/aiff',
      'audio/aac',
      'audio/ogg',
      'audio/flac',
      'audio/webm'
    ];
    
    if (supportedMimeTypes.includes(file.mimetype)) {
      cb(null, true);
    } else {
      cb(new Error(`Unsupported audio format: ${file.mimetype}`), false);
    }
  },
});
```

## 7. **Error Messages to Watch For**

- `"Empty response text from Gemini API"` - API configuration issue
- `"Audio file is empty"` - File upload problem
- `"Could not transcribe audio"` - Audio format or API issue
- `"Failed to process audio message"` - General processing error
